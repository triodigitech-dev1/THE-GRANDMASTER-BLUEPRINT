# Learning Objectives: The Grandmaster Blueprint

> Derived from the Curriculum Map. This document defines program-level outcomes, chapter-level terminal objectives, enabling objectives, and assessment evidence.

---

## How to Use This Document

- **PLO** = Program-Level Outcome
- **C#** = Chapter number
- **C#.#** = Chapter objective code
- **Bloom’s** = Cognitive level targeted
- **Evidence** = Suggested assessment or deliverable
