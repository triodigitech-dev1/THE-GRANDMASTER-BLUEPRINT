# 03 — Calculation and Visualization Lab

## Purpose

A dedicated area for deliberate training of calculation accuracy, visualization, candidate-move discipline, and evaluation, with measurable results. It treats calculation as a trainable skill, separate from knowledge of theory.

## What to Store

- Calculation session logs: positions used, time taken, your lines, and correct solutions.
- Blindfold and visualization exercise records.
- Position sets sorted by theme and difficulty (studies, combinations, complex middlegames, endgame calculations).
- Timed test results and accuracy statistics.
- Notes on calculation method: candidate selection, elimination, checking, evaluation.
- Error classifications (missed resource, mis-evaluation, visualization slip, time misuse).

## Recommended Workflow

1. Record a baseline test (e.g., 10-20 positions, fixed time per position) and store scores.
2. For each session: write your full analysis on paper or in a text file *before* checking the solution.
3. Compare with the solution; classify each error type in the session template.
4. Alternate between untimed depth work and timed practice.
5. Progress gradually: increase depth, complexity, or reduce visual aids (no board, then no notation).

## Expected Outputs

- A logged history of sessions and scores.
- A calculation error taxonomy with frequency counts.
- Measurable improvement in accuracy and depth at fixed time limits.

## Review Process

- Track accuracy, average time, and error types per month.
- Check transfer: do improvements appear in real games (blunders in critical positions in `05`)?
- Avoid inflating results by reusing solved positions; retire them and add new ones.
- Route persistent error types to `08`.

## Suggested Subfolders or Templates

Recommended: `position-sets/`, `session-logs/`, `visualization-drills/`, `test-results/`. Included template: `calculation-session-template.md`.
