# The Grandmaster Blueprint

A structured workspace for developing a complete chess curriculum, from foundations and board literacy through opening theory, middlegame strategy, endgames, and chess psychology.

## How to use this workspace
- Develop and maintain lesson notes as the source of truth.
- Store board positions and game scores in reusable PGN/FEN datasets.
- Derive presentations, worksheets, assessments, and exports from approved lesson content.
- Keep references with the material they support and record versions of published resources.

See each folder's `README.md` for its purpose and suggested contents.
